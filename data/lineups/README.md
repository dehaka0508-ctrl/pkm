# 호연·신오 사용자 라인업

사용자가 제공한 이미지와 후속 수정 사항을 정리한 한국어 원본입니다.
호연 20팀과 현재까지 제공된 신오 9팀, 총 174마리를 포함합니다.

```bash
npm run trainers:regions  # 한국어 원본 → src/data/trainers.json
npm run trainers:xlsx    # 게임 데이터 → data/trainers.xlsx
```

- 메가진화는 이번 반영에서 제외했습니다. 일반 형태로 되돌리고 메가스톤을 비웠습니다.
  일반 형태가 보유할 수 없는 특성은 그 형태의 첫 번째 일반 특성으로 변경했습니다.
  일반 번치코의 가속과 핫삼의 테크니션처럼 일반 형태에도 가능한 특성은 유지했습니다.
- 메가한카리아스 Z는 한카리아스/모래숨기로 반영했습니다.
- 원본 레벨·타입은 참고용입니다. 게임은 기존 규칙대로 Lv.50과 도감의 현재 타입을 사용합니다.
- 개체치·노력치는 기록하지 않습니다. 게임의 역할별 개체값 규칙을 유지합니다.
- 사용자의 추가 요청에 따라 빈 기술과 성격을 실전 데이터로 보완했습니다.
  `@smogon/sets` 2.0.0의 MIT 라이선스 `stats` 데이터(Showdown 래더 사용 세팅)를 사용했고,
  저작권이 별도로 적용되는 `dex` 세팅 데이터는 복사하지 않았습니다.
  기존에 지정된 기술·성격과 이미지의 '도구 없음'은 그대로 유지합니다.
- 털보박사의 6마리는 사용률 세팅에서 기술 4개·특성·도구·성격을 채웠습니다.
  패리퍼의 잔비, 로파파의 쓱쓱 등 비 날씨 조합을 포함하며 세대/포맷은 `supplement_format`에 기록합니다.
- 시라칸은 기존 양날박치기에 폭포오르기·지진·이판사판태클을 더했습니다.
  해루미는 기존 솔라빔에 대지의힘·오물폭탄·기가드레인을 더했습니다.
  기존 구애 도구와 기술을 유지하는 방향으로 Smogon 분석을 참고해 조정했습니다.
- 자두의 독개굴은 성별·특성이 두 가지로 제시되어 `gender_options`와 `ability_options`에
  보존했습니다. 특성은 사용률 데이터의 건조피부를 선택했습니다. 미확정 성별은 `null`로
  두어 게임의 기존 성별 자동 선택을 사용합니다. 무성 포켓몬도 성별을 비웁니다.
- 보완한 필드는 `supplemented_fields`, 성격 선택 방식은 `nature_source`,
  출처 링크는 각 파일의 `supplement_sources`에 기록합니다. 개체치·노력치는 가져오지 않았습니다.
- 중복 포켓몬도 독립 슬롯으로 보존합니다.
- 옛 표기·오타는 도감 이름으로 변환합니다(페리퍼 → 패리퍼, 독엄니 → 맹독엄니,
  태만함 → 게으름피우기, 뛰어오르다 → 뛰어오르기, 본러쉬 → 본러시, 야타열매 → 야타비열매).

추가 자료는 해당 지방 JSON에 누적한 뒤 위 명령으로 반영합니다.
여기에 없는 신오 트레이너와 다른 지방의 데이터는 변경하지 않습니다.

# 포켓 리그 (가제)

포켓몬 배틀을 기반으로 축구 리그 방식을 따온 트레이너 매니지먼트 팬게임입니다.
9개 지방 × 20명, 모두 180명의 트레이너가 지방 리그(홈·원정 38라운드)를 치르고, 지방 컵과 유럽 축구식 PWT(포켓몬 월드 토너먼트)도 함께 열립니다.

> 비공식 팬게임입니다. Pokémon 및 관련 명칭은 Nintendo · Creatures · GAME FREAK의 상표이며, 이 프로젝트는 어떤 공식 단체와도 관련이 없습니다.

## 핵심 규칙

| 항목 | 내용 |
| --- | --- |
| 배틀 | 3대3 싱글. 엔트리 6마리를 서로 공개하고 3마리를 골라 싸움. 실전 룰대로 모든 포켓몬이 Lv.50 능력치로 싸움 (레벨은 훈련으로 100까지, 레벨은 기술 습득·진화에 쓰임) |
| 성격 | 데이터에 성격이 없으면 기술 배치에 맞춰 자동 배정. 포켓몬 쇼다운 랭크전 사용률 세팅(@smogon/sets의 `stats`, MIT, 3~8세대)에서 기술이 가장 많이 겹치는 세팅의 성격을 쓰고, 맞는 세팅이 없으면 물리·특수·변화기 구성과 종족값으로 정함 |
| 개체값 | 트레이너 역할별로 6개 능력 모두 같은 값: 챔피언 31 · 주인공 30 · 라이벌/사천왕/보스 28 · 관장/박사 25 · 기타 22 · 트레이너 20 |
| 지방 기믹 | 칼로스 메가진화 · 알로라 Z기술 · 팔데아 테라스탈 (다이맥스는 엔진 미지원) |
| 달력 | 월/일 단위, 윤년 없음. 시즌은 9월 1일 ~ 다음 해 8월 31일. 1시즌 9월 1일은 월요일 |
| 리그 | 지방별 20명, 홈·원정 38라운드. 9월 첫 일요일 개막, 매주 일요일. 승 3점 · 무 1점, 동률이면 득실(남은 포켓몬 차이) → 다득점 → 추첨 |
| PWT 진출 | 전 시즌 리그 1~3위 + 디펜딩 챔피언 직행. 4위 9명은 프리시즌(8월 셋째 주 수요일) 단판 플레이오프로 남은 자리(보통 5자리)를 다툼. 4위 중 전 시즌 승점 1위는 부전승. 1시즌은 팀 전력 평가로 전 시즌 순위를 대신함 |
| PWT 조별리그 | 32명을 4개 포트로 나눔 (1포트: 디펜딩 챔피언 + 승점 높은 리그 1위들, 이후 나머지 1위 → 2위 → 3위 → 플레이오프 승자 순). 9월 첫 월요일 조 추첨(같은 지방끼리 같은 조 불가), 9월 1~3주·11월 1~3주 수요일에 홈·원정 6경기, 조 2위까지 진출 |
| PWT 토너먼트 | 1월 첫 월요일 대진 추첨(조 1위 vs 다른 조·다른 지방의 조 2위). 16강 1월, 8강 2월, 4강 3월 (1·3주 수요일 1·2차전). 승수 → 득실 → 추가 1판. 결승은 지방 컵 결승 1주 뒤 수요일 3판 2선승 |
| 지방 컵 | 10월 첫 월요일 추첨. A윙·B윙 각 10명이 A~E 자리에 두 명씩. 1R(A~D) 10월, 2R(A-B·C-D·E) 12월, 3R(C/D-E) 2월, 윙 결승 3월 (2·4주 수요일 1·2차전). 결승은 리그 최종 라운드 뒤 수요일 3판 2선승. 1시즌은 무작위, 2시즌부터 전 시즌 홀수 순위 A윙·짝수 순위 B윙, 순위대로 E·D·C·B·A |
| PCT | 포켓몬 챌린지 토너먼트 (PWT와 챔피언스리그-유로파리그 관계). 전 시즌 지방 컵 우승자 + 리그 4~6위 중 PWT 미진출자 직행, 남은 자리는 7위(→8위…)들 중 전 시즌 승점순. PWT와 같은 방식으로 같은 주 목요일 |
| 슈퍼컵 | 2시즌부터 (8월 = 다음 시즌 프리시즌). 8월 마지막 일요일 지방 슈퍼컵(리그 우승 vs 컵 우승, 같으면 리그 2위), 8월 마지막 수요일 월드 슈퍼컵(PWT 우승 vs PCT 우승) |
| 부상 | 플레이어만 받음: PWT 우승 금색병뚜껑(모든 개체값 최대), 리그·지방 컵·PCT 우승 은색병뚜껑(개체값 하나 최대) |
| 상점 | 도구·나무열매·진화 도구·민트·특성캡슐/패치·기술머신·메가스톤·Z크리스탈·테라피스는 모두 사야 씀. 기술머신은 한 번 사면 계속 사용. 레벨업 기술과 배운 적 있는 기술은 언제든 편집 |

### 포켓 매니저와 다른 점 (요청 사항)

1. **완성된 라인업**: NPC 트레이너는 낮은 레벨부터 키우지 않고, 각 세대 게임의 최종전 라인업을 그대로 씁니다(`src/data/trainers.json`). 확실하지 않은 칸은 비워 두었고, 게임은 빈 칸을 **임시 포켓몬 / 자동 기술**로 채워 표시합니다.
2. **NPC 라인업 고정**: NPC는 영입·방출·육성을 하지 않습니다.
3. **수명·은퇴 없음**: 포켓몬은 나이를 먹거나 은퇴하지 않습니다.
4. **시작 방식 2가지**
   - 트레이너로 시작: 180명 중 한 명이 되어 그 라인업(Lv.50)으로 시작
   - 스카우트로 시작: 지방을 고르고 Lv.5 포켓몬을 스타팅 3종 중 1 → 초반 새·벌레·포유류 중 1 → 무작위 3종 중 1 순서로 스카우트해 시작(고른 지방의 트레이너 한 명 자리를 이어받음)

## 플레이어가 하는 일

- **스쿼드**(최대 10마리)와 **엔트리 6마리** 관리, 기술·특성·도구·테라타입 설정, 진화
- **훈련**: 매주 포켓몬별로 레벨 훈련 / 능력(노력치) 강화 / 휴식. 레벨 상한 50
- **스카우트**: 지방(·타입)을 골라 파견 → 2주 뒤 후보 보고서 → 영입. ★는 추정치
- **경영**: 입장료(팬 만족도), 스폰서·굿즈 수입, 식비·유지비, 시설(훈련·스카우팅·경기장) 업그레이드
- **경기**: 상대 6마리를 보고 3마리 선택 → 직접 지휘 / 관전(자동) / 결과만 보기

### 자산·데이터 다시 만들기

PokeRogue 저장소(자산·번역 포함)가 옆 폴더에 있어야 합니다.

```bash
git clone --depth 1 --recurse-submodules --shallow-submodules https://github.com/pagefaultgames/pokerogue ../pokerogue-src
npm run data       # src/data/gen/*.json (한글 이름, 스프라이트 매핑, 임시 포켓몬 후보)
npm run assets     # public/assets/ (스프라이트·배경·UI·애니메이션 묶음)
```

다른 경로라면 `POKEROGUE_DIR=/경로/pokerogue npm run data` 처럼 지정하세요.

### 트레이너 라인업 채우기

1. `data/trainers.xlsx`를 엑셀로 엽니다(또는 게임 [설정 → 라인업 엑셀 내보내기]).
2. '라인업' 시트에서 트레이너마다 6줄(슬롯 1~6)에 포켓몬·도구·특성·성격·기술1~4·테라타입을 **한글 이름**으로 채웁니다. 표기는 '포켓몬목록', '기술목록', '도구목록', '특성목록' 시트를 참고하세요.
3. 반영 방법 두 가지
   - 게임에서 바로: [설정 → 라인업 엑셀 불러오기] (이 브라우저에만 적용)
   - 기본 데이터로: 파일을 `data/trainers.xlsx`로 저장하고 `npm run trainers:import` → `src/data/trainers.json` 갱신
4. 현재 데이터를 엑셀로 다시 뽑으려면 `npm run trainers:xlsx`

`출처` 열에 어느 게임의 어떤 대결을 기준으로 했는지 적혀 있습니다. 레벨은 리그 규칙에 따라 모두 50으로 맞춰집니다.

## 폴더 구조

```
src/
  data/       도감(한글 이름·스프라이트), 트레이너 라인업 JSON, 엑셀 입출력
  battle/     Showdown 엔진 래퍼, AI(기술 선택·3마리 선택), 데미지 추정, 웹워커
  game/       시즌 진행, 리그 일정·순위, PWT, 훈련·진화, 스카우트, 재정, 저장
  render/     Phaser 배틀 화면, PokeRogue 기술 애니메이션 플레이어, 로그→연출 변환
  ui/         Preact 화면(타이틀, 새 게임, 메인 탭, 경기 준비, 배틀)
scripts/      데이터·자산 생성, 라인업 엑셀 변환
public/assets PokeRogue에서 묶어 온 자산
```
